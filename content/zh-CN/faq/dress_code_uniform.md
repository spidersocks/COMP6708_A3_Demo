# 着装要求（无校服）

- BrightNest **不要求校服**。
- 舒适的活动服装和**包跟鞋**最合适（尤其游戏班与拼音描红）。
- 请在外套和水杯上写名字。
- 上课日请避免戏服或拖鞋 — 上下楼梯与活动游戏穿运动鞋更安全。
- 美劳／写作日：旧 T 恤可以；脏手工我们会提供围裙。
