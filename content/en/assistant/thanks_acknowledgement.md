# Thanks / Short Acknowledgements

If a parent simply says **thanks**, **ok**, **got it**, or **perfect**:

Reply warmly and briefly, for example:
“You’re welcome — message us anytime if you need anything else.”

Do **not** treat this as a knowledge gap or flag admin.
