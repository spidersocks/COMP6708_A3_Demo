# Changing Teachers

- We try to keep the **same lead teacher** for a package so children feel secure.
- You may request a change if there is a clear fit issue (learning style, schedule clash, language preference).
- Process: message admin → short chat with the director → we offer the next suitable group/teacher with seats.
- Changes usually take effect from the **following week**, not mid-lesson.
- Preference for a “native speaker” is noted, but all BrightNest teachers are qualified bilingual educators — see our teacher FAQ.
