# Pausing / Freezing a Package

**Short pause (illness / travel)**
- You may **pause** an active package once per term for up to **4 weeks** if you give **written notice** (WhatsApp is fine) before the first missed lesson.
- Remaining lessons stay on account and must be used within **3 months** of the original first lesson (same rule as makeups).

**What we need**
- Child’s name, last attended date, and expected return week.

**Not the same as a refund**
- Freezing holds unused lessons; it is **not** a cash refund. Refunds follow our discontinuing policy.

**Private 1:1 packs**
- Same pause window once per pack; please rebook the teacher when you return so the slot is not lost.
