# Trial Assessment

Keywords: trial, assessment, placement, booking

BrightNest offers a **45-minute Trial Assessment** for new families.

What happens:
1. Brief chat with parent about goals and schedule
2. Play-based language / literacy check with the child
3. Teacher recommendation for a suitable class level
4. Optional provisional seat hold for up to 7 days

Fee: **HK$180** (credited toward the first package if you enrol within 14 days).

How to book:
- Ask the bot for **trial availability**, or
- Call / WhatsApp **+852 9123 4567**, or
- Email **hello@brightnest-hk.example**
