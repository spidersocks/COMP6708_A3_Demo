# 一般上課時段（參考）

| 課程 | 常見時段 |
|------|----------|
| 遊戲班 | 星期一至五上午 09:30–11:30 |
| 拼音 | 平日下午 16:00–18:00；六 09:00–13:00 |
| 普通話 | 平日下午 16:00–18:00；六 09:00–13:00 |
| 創意寫作 | 星期六上午；部分星期四 16:30–17:30 |
| 試堂評估 | 營業時間內預約 |

營業時間：一至五 09:00–18:00；六 09:00–16:00（日及公眾假期休息）。
