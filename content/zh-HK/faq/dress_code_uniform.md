# 穿著要求（無校服）

- BrightNest **唔規定校服**。
- 舒適嘅活動服裝同**包踭鞋**最啱（尤其遊戲班同拼音描寫）。
- 請喺外套同水樽寫名。
- 上課日請避免戲服或拖鞋 — 上落樓梯同活動遊戲著運動鞋較安全。
- 美勞／寫作日：舊 T 恤可以；骯髒手工我哋會提供圍裙。
